# Research

The prior art behind the grand picture, kept as it was written - not generated, not rendered.

- `open-handset-commons/` - the Open Handset Commons model: nine structural concepts a daily-driver
  phone needs (Two Minds, Radio Wall, Notification Sovereignty, Consolidation Path, Platform
  Compatibility, Security Substrate, Update Covenant, Power Covenant, Observatory), the map of
  Android, iOS and the open ecosystem against them, and the prior-art files for Android/AOSP, iOS and
  GrapheneOS. It is the *why* layer of [the grand picture](../docs/picture.md); the best-of-Linux
  column of the feature matrix cites it.

The method it was made with (observatory protocol, prior-art schema, concept extraction) is
domain-free and lives in open-commons-observatory/method. Next: the prior-art files become data
here (a table per project, with sources), so the matrix can cite them row by row.
